## 1. 低功耗(必做,优先级最高)

状态机现状:所有界面 `reset_sleep_delay_all()` 压制睡眠常亮满速跑,关机模式只是"看起来关机"。

### 1.1 关机模式真低功耗

- [ ] 关机模式进 sleep:黑屏待机改 MCU 真睡眠。约束:PB12 系统供电必须保持高。
- [ ] **sfunc_pwrdown 路径禁用**:`sfunc_pwrdown_do()`(func_lowpwr.c)全 IO `GPIOxDE=0`
      → PB12 掉 → 系统断电。确认无任何路径能走到它(含 FUNC_PWROFF),或定制版本保留 PB12。
- [ ] 睡眠方案选型:`sfunc_sleep()`(sniff/retention,RAM 保持)vs 自定义浅睡;
      唤醒后 mode_cb 与引脚状态不丢。
- [ ] 唤醒源:WKO 按键(现有 wko_wakeup_init 已配);PE7 插入中断已注册
      (extab_user_isr_set 上升沿,默认 MODE_ONLY_AWAKEN),睡眠唤醒需改
      `extab_user_isr_mode_set(IO_PE7, MODE_BOTH_AWAKEN_SLEEP_PWK)` 并验证;
      唤醒后状态机消费 vbus_in 事件启判模式序列。
- [ ] 睡眠期间按键识别:key_on 状态机靠 5ms 定时中断,睡眠中定时器停。
      方案:WKO 唤醒后醒着跑 key_on 判长按 3s,非长按重新入睡;确认定时器唤醒后恢复。
- [ ] 睡眠期间 vbus:轮询不可用,依赖 PE7 唤醒沿;确认内部下拉睡眠中保持。

## 6.5 充电控制 PE0(已实现,待验证)

PE0 拉低=开充电,外部上拉,MCU 释放(输入)=关。策略:判模式序列/PC 模式=关(不影响 USB 通信),
充电模式=开(确认非 PC 后),脱机=USB 在位即开;PC/脱机超时或长按进关机时 USB 仍在位
→ 后台继续充电(581 已断电无 USB 通信),拔出才关。已关闭 LOUDSPEAKER_MUTE_EN 让出 PE0。

- [ ] 示波器验证 PE0 时序:插入→判模式期间保持高(关)→进充电/脱机后拉低。
- [ ] 确认功放 MUTE 关闭无副作用(若板上确无功放则无影响;有功放需换 MUTE 脚)。
